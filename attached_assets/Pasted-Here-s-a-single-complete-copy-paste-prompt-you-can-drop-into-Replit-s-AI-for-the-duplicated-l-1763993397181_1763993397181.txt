```js
  excellent: 5000,
  good: 10000,
  fair: 15000,
  needs_work: 25000,
  major_repairs: 40000,
};
```

Again, keep these values configurable.

REALTOR & CLOSING COST SAVINGS:

Assume typical:

* `commissionRate = 0.06` (6% realtor commission)
* `sellerClosingCostsRate = 0.02` (2% seller closing costs)

Compute:

```js
const traditionalCosts = estimatedMarketValue * (commissionRate + sellerClosingCostsRate);
// ~8% of ARV saved when selling to HomeBuyerBoise (no agent, no typical seller closing costs)
```

You can use this in explanatory copy and/or in your risk/margin calculation.

MARGIN RATE:

Add a configurable margin rate to protect profit, e.g.:

```js
const MARGIN_RATE = 0.02; // 2% of ARV as extra cushion
```

OFFER FORMULA (SUGGESTED STARTING POINT):

```js
function calculateOffer(inputs) {
  const {
    estimatedMarketValue,
    condition,
    estimatedRepairs,
  } = inputs;

  const multiplier = CONDITION_MULTIPLIERS[condition] || CONDITION_MULTIPLIERS.fair;

  // Base price after condition discount
  let basePrice = estimatedMarketValue * multiplier;

  // Subtract estimated repairs (if provided or mapped)
  const repairs = typeof estimatedRepairs === 'number'
    ? estimatedRepairs
    : REPAIR_ESTIMATES[condition] || REPAIR_ESTIMATES.fair;

  basePrice -= repairs;

  // Subtract an additional explicit margin for risk/profit
  basePrice -= estimatedMarketValue * MARGIN_RATE;

  // Calculate a presentable offer range
  const anchorOffer = basePrice;
  const offerLow = Math.max(0, anchorOffer * 0.97); // -3%
  const offerHigh = anchorOffer * 1.03;             // +3%

  return {
    offerLow: Math.round(offerLow),
    offerHigh: Math.round(offerHigh),
    anchorOffer: Math.round(anchorOffer),
  };
}
```

NOTES:

* All multipliers and rates are starting defaults designed to protect profit.
* Document them clearly at the top of the module.
* The goal: you **make money** while still presenting a fair, understandable cash price.
